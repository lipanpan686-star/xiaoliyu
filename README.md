# 建筑照片转扁平描边插画 Skill
> AI Skill，用于把实景建筑照片转化带细描边的扁平信息插画。

## ✨特点
- 忠实原建筑形体结构，不魔改造型
- 自定义巧思：纤细轮廓描边，扁平矢量色块
- 自带尺度树木剪影，预留标题文字区域，适合文创、PPT、科普海报

## 📝使用方法
1. 将 `SKILL.md` 导入支持skill机制的AI工具；
2. 上传建筑实景照片；
3. 直接输出插画结果。

## 参数可调
- 想要水彩纸肌理：在规则增加：底层叠加微弱水彩纸张纹理
- 修改描边颜色：替换「纤细白色虚线描边」为对应颜色
- 想要上下拼接版式（原图+插画）：增加要求：输出上下分栏，上方放置原始照片，下方生成插画

## 示例对象
天坛、古建、地标建筑、园林建筑实拍图。
